# FitCart – Fitness Multi-Vendor E-Commerce Platform

## Project Overview

FitCart is a fitness-focused multi-vendor e-commerce platform developed using Java Swing, JDBC, and MySQL.

The system supports three main roles:

- Buyer
- Seller
- Admin

Buyers can browse products, search products, manage their cart and wishlist, and place orders.

Sellers can manage products, inventory, and orders.

Admins can manage users, products, categories, orders, and inventory.
